Guide d'utilisation

Gestion des scénarios

Les scénarios vous permettent de définir des configurations personnalisées avec des menus et des paramètres spécifiques.

  • Créer un scénario : Cliquez sur "Créer un Scénario" et remplissez :
    • Nom et Description du scénario.
    • Mode : Apprentissage, Entraînement, Examen.
    • Difficulté : Débutant, Intermédiaire, Avancé.
      • À noter que les niveaux de difficulté sont uniquement utilisés lorsque le mode sélectionné est Entraînement.
    • Temps alloué, allant de 5 à 60 minutes.
  • Menus dans un scénario :
    • Vous pouvez ajouter jusqu'à 2 menus maximum.
    • Il est possible d'ajouter 2 fois le même menu.
    • Utilisez les boutons "Ajouter un menu" pour inclure un menu existant.
    • Sélectionnez parmi la liste des menus existants lequel vous souhaitez ajouter.
  • Validation : Activez les options de validation selon vos besoins :
    • Position : Vérifie si les objets sont placés correctement.
    • Rotation : Valide l'orientation des objets.
    • Ordre : Vérifie l'ordre des objets.
  • Modifier un scénario : Utilisez le bouton "Modifier" pour ajuster les paramètres existants.

Création et Modification des menus

Les menus sont composés d'une entrée, d'un plat et d'un dessert, et doivent inclure des ustensiles.

  • Créer un menu : Cliquez sur "Créer un Menu" et définissez :
    • Nom et description du menu.
    • Entrée, Plat principal et Dessert.
  • Ajout d'ustensiles (Drag & Drop) :
    • Faites glisser les ustensiles disponibles depuis la liste à gauche.
    • Une fois placés, vous pouvez cliquer sur un ustensile pour ouvrir le panneau de configuration.
    • Options de configuration :
      • Position X / Y : Ajuste la position de l'objet.
      • Rotation : Définit l'orientation de l'ustensile.
      • Ordre de placement : Gère l'ordre de placement des objets dans le menu.
    • Une fois placés, vous pouvez maintenir le clique gauche sur un ustensile pour le déplacer.
    • Si vous sélectionnez plusieurs ustensiles à la fois, un bouton "Centrer" apparaîtra afin de vous permettre de centrer la sélection sur la table (Attention, il s'agit du center de la sélection !).
    • Un ustensile ne peut exister qu'une seul fois sur la table.
  • Modifier un menu : Accédez à l'éditeur pour ajuster les plats ou repositionner les objets.

Sauvegarde et Gestion des éléments

  • Utilisez le bouton "Sauvegarder" pour enregistrer vos modifications.
  • Vous pouvez supprimer un scénario ou un menu en cliquant sur "Supprimer".
  • Les menus supprimés ne seront plus disponibles dans la liste des menus pour les scénarios.

💡 Astuces

  • Si vous devez créer un scénario avec des menus non existants, veuillez d'abord créer vos menus pour pouvoir ensuite les ajouter au scénario.
  • Placez d'abord les objets principaux comme l'assiette (au centre de la table, coordonnées 500 300), puis ajoutez les autres ustensiles.
  • Pour une meilleure précision, utilisez les valeurs X/Y pour positionner les objets.
  • Si vous avez placé des ustensiles sur la table, mais que vous vous êtes trompé, vous pouvez le supprimer depuis la panneau de configuration, mais attention à l'ordre de placement des objets !
